# Demo-Bank-App
A side project to demonstrate backend knowledge on building a seamless onboarding process, capturing user info. Displaying them while making sure it remains interactive, creating role-based feature and lots more.
  
Case Study: Banking Workflow Simulation
  
1. Problem
Learners and small teams often need a simple way to demonstrate how banking workflows (onboarding, transactions, history) function. Static pages don’t show backend logic, and manual demos lack persistence.

2. Solution
I built a DemoBank app using PHP with:
- Onboarding flow — user registration and login
- Transactions — transfer, withdraw, deposit
- Transaction history — persistent records for each account
- Responsive UI — clean forms and layouts for usability

 3. Outcome
- Functional proof — every transaction updates history correctly
- Scalable foundation — can be extended with authentication, APIs, or cloud deployment
- Portfolio value — demonstrates backend logic beyond static sites

4. Reflection
This project taught me how to structure PHP applications around real workflows. By focusing on onboarding and transactions, I proved backend logic without overloading the app with unnecessary features.
